<h1 align="left">ONLINE COURSES PLATFORM</h1>

###

<p align="left">Overview<br><br><br>The Online Course Platform is a web-based application that allows users to explore, enroll in, and manage online courses. The platform supports features like real-time chat, video streaming, user authentication, and more. The project is divided into two parts:<br><br>Frontend: The user interface of the platform built using modern web technologies.<br><br>Backend: The server-side logic and database management.</p>

###

<h2 align="left"></h2>

###

<h2 align="left">Features</h2>

###

<p align="left">Course Management: Admins can create, update, and delete courses, add an assignments and quizzes.<br><br>User Authentication: Users can sign up, log in, and manage their profiles.<br><br>Real-Time Communication: Chat with other support team via socket.io.<br><br>Stripe Integration: For handling payments and subscriptions.<br><br>Video Streaming: Watch course videos directly on the platform.<br><br>Course Analytics: Visualize course progress and analytics with charts.</p>
